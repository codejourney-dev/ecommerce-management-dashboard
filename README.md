# E-Commerce Management Dashboard

A full-stack e-commerce management dashboard designed for the Iranian market.

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM

### Database
- PostgreSQL
